# How to teach me or explain to me

## Instructions
- Should only be made when 2 or more repositories/data sources are needed
- Should have 1 function, `execute` in them
- Usages of the UseCase should have useCase as a suffix
- Ensure unit tests are updated or implemented when working with UseCases
- Should be platform-agnostic
- Should have KDocs written for them to better explain
