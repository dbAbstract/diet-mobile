# How to teach me or explain to me

## Instructions
- Should be framework and platform-agnostic
- Implementations should have `Impl` as a suffix
- Ensure getters are made for iOS in iOS main as these are Koin components
- Ensure test coverage is sufficient
- KDoc the contract for better understanding, the KDoc should not explicitly point to implementation details, but rather just simply explain the purpose of the various APIs
